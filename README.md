# ⚡ JARVIS AI ASSISTANT

> **Высокопроизводительный локальный голосовой ИИ-ассистент для Windows со зрением экрана, базой данных приложений и полным управлением системой на базе Zig 0.16 и GPU.**

---

## 🌟 Ключевые возможности

### 🎙️ 1. Кристально чистый голосовой ввод (STT)
* **Whisper Small / Base**: Автоопределение и локальное распознавание русской речи без отправки данных в облако.
* **Pre-roll Ring Buffer (300 мс)**: Кольцевой буфер упреждения сохраняет первый слог и согласные звуки до срабатывания детектора голоса (VAD) — фразы больше не обрезаются.
* **Auto-Gain Normalization**: Автоматический подъем уровня тихого звука до оптимальной амплитуды Whisper без искажений.
* **Echo Suppression**: Блокировка захвата микрофона во время ответа ассистента.

### 🗣️ 2. Естественная нейросетевая озвучка (TTS)
* **Piper Neural Voice (`ru_RU-dmitri`)**: Качественный мужской голос с настроенным темпом (`--length-scale 1.02`) и паузами между предложениями.
* **SAPI Fallback**: Автоматическое переключение на системный голос Windows при отсутствии внешнего движка.

### 👁️ 3. Зрение экрана (SmolVLM-256M)
* **Аппаратный Win32 GDI-захват**: Мгновенный снимок экрана (`<15 мс`) без вызова сторонних блокируемых скриптов.
* **Мультимодальная модель SmolVLM-256M-Instruct**: Анализ содержимого экрана, открытых окон, приложений, кода или текста прямо на GPU (порт `8081`).

### 🗄️ 4. База данных и умный запуск приложений
* **Автоматическая индексация (`cache_apps.json`)**: Сканирует ярлыки меню «Пуск», рабочего стола и системных каталогов (140+ программ).
* **Нечеткий поиск (Fuzzy Matching)**: Понимает русские синонимы, сленг и транслитерацию (*«дискорд»*, *«телега»*, *«хром»*, *«стим»*, *«обс»*, *«код»*, *«музыка»*, *«аида»*, *«автобернер»*).
* **Глубокий поиск (Deep Search Fallback)**: Если ярлык отсутствует, Jarvis сканирует `Program Files` и `%LOCALAPPDATA%` на наличие подходящего `.exe`.

### 🌐 5. Чистые ссылки и поиск информации
* **Punycode Sanitizer**: Защита от мусорных доменов — автоматическая нормализация любых ссылок к каноническим HTTPS (`https://youtube.com`, `https://vk.com`).
* **Онлайн-факты**: Быстрый поиск кратких справок через Wikipedia и DuckDuckGo Instant Answer API.
* **Чтение веб-страниц (`read_webpage_content`)**: Чтение и пересказ содержимого сайтов без рекламы и разметки.

### 💻 6. Прямое управление Windows
* Управление громкостью (`0-100%`), Mute, мультимедиа-клавиши (пауза, следующий трек).
* Сворачивание всех окон (Win+D), закрытие активного окна (Alt+F4), переключение на окно приложения.
* Блокировка ПК (Win+L), выключение с таймером, отмена выключения, спящий режим.
* Очистка корзины, информация о батарее, оперативной памяти и нагрузке CPU.
* Работа в системном трее Windows (`--tray`).

## 🚀 Быстрый запуск

### 1. Автоматическая установка моделей и бинарников
В командной строке от имени пользователя:
```cmd
install.bat
```
*(Скрипт загрузит языковую модель Qwen2.5-3B, Whisper, Piper TTS, SmolVLM-256M и скомпилирует проект).*

### 2. Запуск ассистента
```cmd
run.bat
```

## 🏗️ Архитектура проекта

```
Djarvis-huyarvis/
├── run.bat                 # Главный запуск ассистента
├── install.bat             # Установщик компонентов
├── jarvis/
│   ├── build.zig           # Скрипт сборки Zig 0.16
│   ├── cache_apps.json     # Локальная база индексированных программ
│   ├── scripts/
│   │   ├── run_all.bat          # Одновременный запуск LLM + VLM + Jarvis
│   │   ├── run_llama_server.bat # Qwen2.5-3B GPU сервер (порт 8080)
│   │   ├── run_vlm_server.bat   # SmolVLM-256M Vision сервер (порт 8081)
│   │   └── index_apps.ps1       # Индексатор ярлыков меню Пуск и Desktop
│   ├── src/
│   │   ├── main.zig        # Точка входа, REPL и системный трей
│   │   ├── router.zig      # Диспетчер инструментов и диалоговой истории
│   │   ├── win32.zig       # Win32 API, GDI-экран, Fuzzy App Search, URL Sanitizer
│   │   ├── llm.zig         # HTTP-клиент локального LLM-сервера и JSON Schema
│   │   ├── stt.zig         # Whisper STT, VAD, Pre-roll буфер и Auto-Gain
│   │   ├── tts.zig         # Piper Neural TTS и SAPI интеграция
│   │   ├── audio_bridge.c  # Miniaudio драйвер захвата микрофона и GDI-скриншотов
│   │   └── tray.zig        # Иконка и меню в системном трее Windows
```

## ⚙️ Системные требования
* **ОС**: Windows 10 / 11 (64-bit)
* **GPU**: NVIDIA / AMD / Intel с поддержкой Vulkan / CUDA (~2.2 ГБ видеопамяти)
* **RAM**: 4 ГБ ОЗУ
* **Язык разработки**: Zig 0.16 + C99
